# Diljot Singh — Web Developer Portfolio

Professional, responsive, static portfolio website for independent developer Diljot Singh.

## Contents

- `index.html` — landing page and four featured projects
- `styles.css` — responsive layout, typography, and design styles
- `script.js` — accessible mobile navigation and automatic footer year
- `assets/projects/` — genuine imagery obtained from featured clients' websites (not complete screenshots)
- `assets/Diljot-Singh-Resume.pdf` — downloadable résumé
- `assets/favicon.svg` — site icon

## Run locally

Open `index.html` in a browser or run `python3 -m http.server 8000` in this folder and visit <http://localhost:8000/>.

## Publish using GitHub Pages

1. Create a **public** GitHub repository named **`portfolio-diljot-singh`** under the `diljott3-byte` account. Do not initialize with a README if you're uploading a fresh file set.
2. Upload **the contents** of this folder to the repository root (`index.html`, `styles.css`, `script.js`, `README.md`, `assets/`).
3. Visit **Settings → Pages → Build and deployment** and choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. Once Pages reports a successful deployment, the expected site URL is <https://diljott3-byte.github.io/portfolio-diljot-singh/>.

The repository URL, once created, will be <https://github.com/diljott3-byte/portfolio-diljot-singh>.
